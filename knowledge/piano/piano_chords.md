# Piano Chords

## Piano Chords

A piano chord is a group of notes played together.

Chords are commonly built from scales and are used to create harmony, accompany melodies, and form chord progressions.

When learning piano chords, it is useful to understand:

- The notes in the chord
- The root note
- The chord type
- Which fingers are used
- Chord inversions
- How the chord connects to other chords

## C Major Chord

The C major triad contains:

C - E - G

A common right-hand fingering is:

- Thumb: C
- Middle finger: E
- Little finger: G

A common left-hand fingering is:

- Little finger: C
- Middle finger: E
- Thumb: G

C major is a useful beginner chord because it uses only white keys.

## Chord Inversions

A chord inversion changes which chord note is played as the lowest note while keeping the same notes.

For example, C major contains:

C - E - G

Root position:

C - E - G

First inversion:

E - G - C

Second inversion:

G - C - E

Inversions are useful for making chord changes smoother and reducing unnecessary movement between chords.

## Piano Chord Fingering

When learning a new chord:

1. Identify the notes in the chord.
2. Find the root note.
3. Place the appropriate fingers on the notes.
4. Play the notes together.
5. Check that each note sounds clearly.
6. Practice the chord slowly.
7. Practice changing between the chord and other familiar chords.

## Chord Changes

Chord changes are the movement from one chord to another.

For example:

C major → G major → A minor → F major

This is a common four-chord progression.

Practice changing between chords slowly before increasing the speed.

## Major and Minor Chords

Major and minor chords have different sounds and structures.

A major triad contains:

- Root
- Major third
- Perfect fifth

A minor triad contains:

- Root
- Minor third
- Perfect fifth

For example:

C major:

C - E - G

C minor:

C - Eb - G

The difference is the third of the chord.

## Why Piano Chords Matter

Learning piano chords can help musicians:

- Accompany songs
- Understand harmony
- Play chord progressions
- Support melodies
- Write music
- Improve coordination
- Understand music theory

## Practice Tips

When practicing piano chords:

- Start slowly.
- Practice each chord separately.
- Make sure every note sounds clearly.
- Practice moving between two chords.
- Use a metronome when appropriate.
- Practice both hands.
- Learn inversions after becoming comfortable with root-position chords.
- Gradually increase speed while maintaining accuracy.
